# VIVANCOFFEE ☕

Página web de VIVANCOFFEE, una cafetería enfocada en ofrecer una experiencia visual moderna y atractiva para sus clientes.

## 🚀 Tecnologías

- React
- JavaScript
- HTML5
- CSS3
- Vite
- Git & GitHub

## 📋 Características

- Diseño responsive
- Hero section
- Galería de imágenes
- Menú interactivo
- Loader de carga
- Navegación entre secciones
- Adaptación a diferentes dispositivos

## 🛠️ Instalación

Clona el repositorio:

```bash
git clone URL_DEL_REPOSITORIO

Entra al proyecto:

cd Vivancoffee-React

Instala las dependencias:

npm install

Ejecuta el proyecto:

npm run dev

Después abre la URL que proporciona Vite en la terminal.
